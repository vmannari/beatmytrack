# Beat my track — current music direction

This file provides a starting context, not permanent artistic law. `docs/music/STATE.md` is the live source of truth.

## Product context
Beat my track is a light, skill-based top-down racing game with compact tracks and repeated runs. Music must survive retries and coexist with engine, tyre, collision, UI and environmental sound. The soundtrack should help the game feel distinctive without taking over the player's attention.

## Current preference snapshot
Based on the latest user feedback available when this skill was created:
- Music should function primarily as **unobtrusive background music** during racing.
- The user is interested in **organic, human, instrumental** sound rather than EDM or conspicuously electronic production.
- Earlier synthetic/procedural renders were rejected, especially disturbing or mechanically repetitive opening layers.
- An earlier distorted-rock finale was rejected. Do not equate “organic instrumentation” with “intense rock arrangement.”
- The user likes the concept of musical development with good driving, but the exact shape/intensity of any climax remains subject to listening feedback.
- Reference artists/games are directional inspiration, not a request to imitate copyrighted works.

If local project documentation such as `docs/MUSIC_MODULAR_BANK.md` conflicts with this snapshot, reconcile it with the user and update `STATE.md`.

## Design ambition
The soundtrack should become memorable through a coherent sound world and musical identity, not through maximum density. Different biomes may have different palettes while still feeling like the same game.

## Useful reference lessons
- **Ori / Journey:** thematic identity can transform with context; payoff is stronger when it grows from known material.
- **Zelda:** modular music works when modules are deliberately composed to connect, not merely because they share a key.
- **Crypt of the NecroDancer:** game action and musical structure can reinforce one another, but Beat my track should not force driving actions onto a beat.
- **Hotline Miami:** a strong, coherent aesthetic can be more memorable than stylistic breadth.
- **Hades / Outer Wilds:** distinctive instrumentation works best when it belongs to the game's world and role.

Do not turn these references into a genre checklist.
