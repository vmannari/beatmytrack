**C10K01 — Offline geometry and allocation.** The new `game/vehicle/car_budget_reduction.gd` loads immutable source-keyed mesh resources. It runs after sibling batching, allowing useful reductions across previously tiny pieces, and before transform-frame batching. There is no runtime decimator. Missing resources, changed source geometry, wrong source metadata, material-slot mismatch or changed bounds retain the original mesh. Its mesh cache is bounded to 256 entries. Challenger exits before lookup.

Most pieces use offline Blender limited dissolve and retessellation. Original source-corner IDs survive the operations; the Godot packer selects those original encoded vertex records. Positions, normals, UVs and other retained attributes therefore remain exact source values, while connectivity and interpolation change. Mirror regions restore components that would disappear or lose their bounds. Rally's stock bonnet keeps its original topology. Kart uses the existing native index candidates for static geometry; its three steering meshes and all ten moving-driver poses remain protected. Boundary simplification on eligible Kart/Forklift pieces is an explicit lower-detail choice. These operations do not establish a maximum surface-distance error.

The offline pipeline is `game/tests/bake_car_10k.gd`, `export_car_10k_surfaces.gd`, `export_car_10k_roles.gd` and `scripts/dissolve_car_10k.py`. Blender **4.5.15 LTS** runs with factory startup and auto-execution disabled, consumes exported arrays, and never opens or saves an owner Blender project. The published set contains **710 resources** for the five included IDs. Source-key/encoded-attribute checks exercise 1,673 real changed-part observations across stock and all offered replacements.

**C10K03 — Appearance and performance tradeoff.** This density has a visible cost. Tyres, helmets, wheel arches, body highlights and small fittings are more angular. Some close details and the translucent ghost's internal lines are simpler. The comparison images are the review evidence; this is not an appearance-identity claim. In exchange, near/master geometry is about 46–60% smaller for the included stock cars, and active mesh buffers are smaller. Pixel/shader work, CPU submission, track geometry and shadow work remain separate costs, so this does not imply the same percentage FPS gain.
