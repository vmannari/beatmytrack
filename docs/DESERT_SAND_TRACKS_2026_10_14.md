# Lighter Desert road and Grass-sand tire tracks

Owner request, 2026-10-14: use the tire-track treatment seen on sand in the Grass biome, lighten the Desert road slightly, and match the marks to that road colour.

Requirements: DST01 shared sand tread/groove/opacity; DST02 modest road lightening with continuous bridge mouths; DST03 matching road/mark pigment; V05 retained bounded rendering and first-use preparation; G01/R01 retained canonical driving, dust and replay; Q01 actual evidence and limitations.

The road pigment changes from `9f8052` to `ac8b5a`. Only `TrackTheme.DESERT[0]` changes; shoulders, dunes, artwork, sun, lighting and camera retain their existing values. Ground roads and native/creator bridge decks already share this palette. The visual kit advances from 198 to 199 to fence prepared geometry that includes bound palette materials.

Desert tracks retain the shared four-vertex/two-triangle ribbon and now use the same tread/centre/shoulder contrast and analytic groove normal as Grass-biome sand. The Desert-only flat-normal, softened-tread and additional high-pressure darkening overrides are removed. Maximum opacity changes from 0.24 to the shared sand value of 0.52. The matte Desert specular treatment remains. A `source_color` uniform binds the exact road pigment, without the previous 0.92 RGB multiplier. Shaded grooves naturally have different light values from the flat road while sharing its base pigment.

No new textures, geometry, draws or samplers are introduced by this change. Width, relief, endpoint joins, pressure interpolation, four-wheel contact/intensity sampling, 0.32 m spacing, the 16,384-slot ring, bridge clipping and covered first draw are retained. This task does not edit dust, canonical physics, handling, content contracts, scoring, replay or camera code.

Changed files: `game/vehicle/skid_trails.gd`, `game/track/track_theme.gd`, `game/track/native_track_visual.gd`; review-only extensions to `game/tests/capture_desert_tire_marks.gd` and an optional output folder in `game/tests/test_trail_render_preparation.gd`; this report, `AGENTS.md`, `DEVELOPMENT_STATUS.md` and `docs/PHASE_0_PLAN.md`. Build identity/project version files are regenerated by the existing launcher and excluded from the task checkpoint.

The capture's optional `--extended` records cornering and five slightly displaced overlapping braking passes. `--baseline` loads the saved entry tire renderer and rebinds the old road pigment in the frozen native scene; it does not swap live workspace source files. The baseline tire renderer uses the live car's exact wheelbase/track width. The diagnostic clears the automatic pause overlay before every saved frame. All captures use detached presentation state and preserve the actual canonical state snapshot, cells and content hash; these are cosmetic samples, not completed races or player telemetry. Dust is deliberately absent from the frozen comparison.
