# Track editor placement latency — 2026-10-18

EPL01 removes unnecessary full scene replacement after ordinary object edits. EPL02 keeps expensive road/terrain preparation away from input processing and cancels obsolete preparation. EPL03 retains exact scenery, collision, local saving, undo/redo and existing cache bounds. G01/R01/Q01 cover unchanged racing and native verification.

The original editor reused its scene only for tyre changes. Placing a tree or container rebuilt terrain, roads, cover and props. Desert's road depression also subdivided and shaded whole meshes on the main thread. Winter recalculated snow-marker positions on that thread after each edit. On the disposable 24-piece circuit, a Desert tree placement took 12,324 ms to settle, including a 5,882 ms frame interval; the corresponding Winter placement included a 937 ms interval.

The preview worker now computes an identity from the actual visible ground, road raster, bridge/kerb data, grid and finish stripe. Solid prop collision stamps that render as the same ground do not invalidate the scene. Changed road exclusion textures receive private material bindings; cached scenes keep their original bindings. Terrain paint, road obstruction, extent changes, bridges and changed finishes still invalidate the appropriate scene. Existing incremental prop groups and generated scenery remain responsible for prop updates.

Bridge/road-height preparation and exact Desert subdivision/normal sampling run as cancellable jobs. Only plain mesh arrays cross from deformation workers to main-thread uploads. The old scene and the existing immediate road overlay remain visible while the new detail prepares. Completed Desert meshes can be borrowed from the retained scene when their original streams, transforms, refinement choice and the complete depression field match. These are existing scene-owned resources, cleared from the temporary lookup after application; no new persistent mesh cache or byte budget is added. Winter cover positions are prepared by the existing compiler worker, and unchanged marker geometry uses the existing bounded auxiliary cache.

Runtime files: `game/core/app.gd`, `game/editor/editor_world.gd`, `game/editor/preview_ground.gd`, `game/editor/prepared_track_cache.gd`, `game/track/native_track.gd`, `game/track/native_track_visual.gd`, `game/track/desert_road_relief.gd`, and `game/track/winter_scenery.gd`. The new placement regression and frozen original Desert deformation fixture live under `game/tests/`; the existing workflow and road-approval fixtures now await actual app startup. Existing unrelated working-tree changes, including concurrent Garage newspaper work, are preserved. Canonical compiler/physics/rules, document formats and backend contracts are unchanged.

New roads still need global road-union and detailed terrain preparation. The Desert example takes about 13 seconds for full detail in the background; this work is not claimed eliminated. Cold native shader/driver work also remains: first biome openings and first new surface combinations produced visible one-time stalls in rendered runs. An initial large container model can still take roughly 0.1–0.2 seconds in its input handler. Owner workflow acceptance and physical-device measurements remain.

The regression checks exact independent compiler identity/cells/deck and durable WIP for placements and history; all five biomes retain ground after ordinary tree/container/tyre placement. It compares retained ground arrays and actual native pixels with a complete fresh build, compares synchronous/worker deformation against the saved original, exercises rapid placement/history and bounds, and leaves during active preparation. Later native checks also place an actual solid object over a road and compare that replacement with a fresh scene.

Completed checks: placement 179 headless, 191 Compatibility and 184 desktop Mobile/Vulkan; existing editor workflow 252, retained-object/save regression 47, App 101 and parser 857 scripts. The headless and Mobile runs preceded the additional solid-on-road case; Compatibility includes that case and its fresh-scene pixel comparison. All listed checks pass. Full native pixels for the five ordinary object-edit scenes match fresh rebuilds on both renderers. Rendered timing observations are not used as paired performance claims; cold shader work and concurrent unrelated checks affect them.

The older road-approval suite completes 40 checks with four failures: three expect a WIP write to have finished while the existing deferred save is still in flight, and one expects a particular scene object to remain in the bounded history cache. A separate runtime snapshot using all seven saved original runtime files, shared read-only asset/import junctions, disposable storage and the same startup-corrected test reproduces those exact four failures. That suite is not claimed as passing; the new checks wait for actual preparation and verify durable document contents, latest collision identity and cache bounds. Original comparison provenance uses per-file hashes; the snapshot has no tracked build inputs of its own, so its generated build identifier is not a source identity.

Initial attempts are retained. The first direct PowerShell call was blocked by script execution policy. Restricted native runs encountered Windows log/certificate-store access errors; their wrapper commands failed even when the child produced completed observation reports. Final native commands use disposable workspace APPDATA with native execution. An initial overly strict ground identity included the full exclusion image and reproduced retained-scene assertion failures; private texture rebinding corrected that. A test-only shortcut around Garage startup initially triggered its profile-rebuild guard recursively; the fixture now skips that unrelated startup guard while exercising the unchanged editor callbacks. The older workflow/road-approval fixtures originally opened the editor after only one frame; real startup subsequently replaced their scenes. Waiting for `startup_complete` fixes their fixture lifecycle without removing an assertion. No game guard was weakened.
