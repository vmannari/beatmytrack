## Behavior and changed files

- `game/ui/menu_page_swipe.gd` (and `.uid`): touch recognition owns a gesture according to its starting position. Horizontal intent now claims after 6 logical units (latest owner correction); 32 logical units arm commitment; dragging back within 12 units cancels it. Release uses the last displayed drag instead of lift-coordinate jitter. Initial vertical jitter can become horizontal intent; later vertical drift does not revoke a claimed swipe. Below-threshold, unclaimed vertical, canceled and two-finger gestures do not navigate. Ordinary button taps still activate; a swipe starting on a button never fires its action. Native scrolling, text entry, ranges/sliders, popup selectors and press-action controls retain their input. Visible drawers/dialogs block page gestures.
- `game/core/app.gd`: swiping left advances Race -> Create -> Garage; right reverses, with no wrapping. Create means the biome/draft menus. Reopening creation choices preserves the current document. The editor canvas retains its existing pan/edit gestures. Release completion uses a 180–320 ms sine ease-in/out; ordinary page returns use 280–380 ms with the same gentle start/end. A growing gutter reaches 64 logical units between visible pages. The logo, tabs, account and Settings stay fixed; both outgoing and incoming content/scenery slide in a viewport clipped below the header. Full-screen scenic framing is retained inside that clip. Outgoing content ignores GUI input and stops processing; swipe completion parks it as an inactive reverse neighbor; leaving the tab group and starting a race clean up transitions. A new press settles an earlier animation before hit-testing, allowing rapid consecutive swipes while retaining carousel ownership. The existing track-selection slide is independent. Same-tab refreshes are immediate.
- `game/tests/test_menu_page_swipe.gd` (and `.uid`): real viewport-dispatched touches at 1280x720 and 960x540 cover both directions, boundaries, draft preservation, cancellation, multitouch, button taps, carousel scrolling/edge ownership, leaving the carousel, dialogs, editor panning, animation progress/disposal and rapid replacement.
