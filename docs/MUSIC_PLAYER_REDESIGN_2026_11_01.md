# Music player and cover redesign - 2026-11-01

The Garage player now has a persistent now-playing card, previous/pause/next controls, volume and a scrollable list of all fourteen tracks. A single tap or click on a row plays that track; tapping the paused current track resumes it. The highlighted row and now-playing card identify the active selection. The existing gesture-aware scroll control distinguishes swipes from taps. The physical Garage sleeve box follows the selected record; music settings, automatic playback order and race silence are retained.

Fourteen individually generated full-bleed driving illustrations replace the previous vector motifs. `game/assets/music_covers_v2/provenance.json` records every original built-in image generation prompt and output hash. Godot import settings limit each texture to 256 pixels and enable mipmaps, retaining the previous cover resolution while keeping the original generated PNGs in the repository. Source PNGs total approximately 36.22 MiB. No source MP3s were changed.

The actual App was exercised in Godot 4.7.2 Compatibility at 960x540, 1280x720 and 1600x900, with isolated user data and the scoped crash-dialog wrapper. The App regression passed 39 checks covering control bounds, direct mouse/touch selection, touch scrolling without accidental playback, pause/resume, keyboard activation and current-track indicators. The separate soundtrack regression passed 43 native checks for imported covers and audio, save migration, selection, playlist advancement and decoded Music-bus output with a dummy audio driver. A sandbox root-certificate-store read error was reported by Godot; these offline tests do not use the network. No physical-device or subjective music review was performed.
