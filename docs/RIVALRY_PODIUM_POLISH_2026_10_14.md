The old texture resolution was derived from layout units. Podium now uses the **same stretch/screen-transform calculation as CarShowroom**, at twice displayed pixel density with the Garage's four-sample 3D MSAA. Each target is capped at 1536×768 while preserving aspect. A native 2.5× scale fixture proves a logical 120×64 pane renders at 600×320 rather than enlarging a small texture.

Both tested renderers retain white RGB under zero alpha (`ffffff00`). `rivalry_car_composite.gdshader` removes that matte before interpolation, composites premultiplied coverage, and respects inherited canvas tint/opacity. Partially covered MSAA silhouette pixels use an opaque colour within one source texel; transparent shadows use renderer-appropriate resolve conversion. The footprint is bounded, opaque source colours stay unchanged, and no extra geometry/image asset is added. A controlled unshaded green silhouette against navy produces **zero pale-fringe pixels** across 461 Compatibility /504 Mobile edge pixels. This is a rendered-pixel test, not only a material-property assertion. Godot's [transparent viewport tutorial](https://docs.godotengine.org/en/stable/tutorials/shaders/using_viewport_as_texture.html) informed the premultiplied composite; the clear-matte and MSAA behavior were measured in the actual pinned renderers.

The preview makes three bounded first-draw refreshes so shared radiance is ready, then freezes. Weak preparation references safely handle closing/hiding the pane. Final settled menu work is 141 draw calls; deliberately forcing all three native car targets to render continuously raises that to 515, then restoring one-shot mode returns to 141. These desktop counts do not establish phone performance; initial preparation now pays higher resolution/antialiasing/shadow cost.

Reflection ablation disables only environment reflection and compares opaque car pixels. Final mean summed RGB-byte deltas range 2.46–7.48 in Compatibility /10.98–20.76 in Mobile across the five vehicles, proving reflection contribution. The Compact comparison also checks original pigment/roughness/metal/specular/clearcoat equality and identical Garage light transforms, shadow flags and shared sky.

Initial development trials exposed a white zero-alpha rectangle with naive premultiplied blending, a shader helper's invalid access to TEXTURE, nonreflective legacy paint on other chassis and a missing-metadata lookup. These were corrected. Restoring Garage MSAA exposed Mobile's linear-light matte fringe (303 pixels); conversion alone left91, and bounded interior-colour resolve removes it without loosening the edge assertion. Earlier bespoke material/light values were replaced after the owner's Garage comparison; the final Compact uses original Garage finishes. No failing invariant was weakened and no unrelated model assets were regenerated.
