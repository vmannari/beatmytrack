Body and Accent controls recolor the model immediately. Closing the compact color picker saves that car's opaque RGB colors through the existing atomic LocalRecords transaction. The picker provides hue/saturation/value and hex input and fits the 960?540 layout. Reset paint restores that car's authored palette. A failed save restores its last committed colors and presents the existing actionable storage notice. Each car retains independent colors, and driving construction reads the saved livery. The existing LocalRecords schema accepts the new optional `vehicle_liveries` field without changing old record files, timing keys or handling contracts. This is the base for future shape/pattern layers; arbitrary paint placement, texture patterns, decals and cloud cosmetic synchronization are not implemented in this slice. No placeholder customization controls or implementation labels were added to the game.
