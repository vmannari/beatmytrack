# Tablet phase profiling method

TPP01 measures app startup through rendered menu content, first/repeat menu entry, local race preparation and same-Game retry on the physical OPD2403. TPP02 preserves the installed APK, authored tracks and personal-best dictionaries. TPPQ01 checks the observer, source identity, visual cache identities and production race invariants.

The task uses the exact installed source snapshot in a private build root. Five files gain bounded debug observations or diagnostic-only isolation guards; three additional scripts implement the local observer and embedded track fixtures. The shipping workspace is not the source of the temporary APK. Stock and marker-inactive temporary-client process launches control the observer's startup cost. All existing app and driver caches remain; these are process-restart observations, not virgin-driver or cleared-storage experiments.

Startup records `APP_READY` separately from actual page readiness. The latter requires the intended page, completed feature load, applicable asynchronous page state and rendered draw fences. Rivalry additionally requires standings and podium-car presentation. Menus include the existing transition and final draw; page readiness is observed rather than replaced. Daily distinguishes ready data from an actionable failure. Garage keeps direct entry, the normal showroom and both reflection views; no modal loading screen is introduced. Editor uses a private draft library and restores the original library/document after its worker and writes finish.

Race fixtures are the existing verified oval and Star document. The production Game and loading code run with ordinary settings, five laps and countdown360. The controller freezes the Game at tick zero before another yield; it checks that retry also remains at tick zero. Private preference/condition files prevent diagnostic Game teardown or retry from saving over the owner's records. Diagnostic race telemetry, rating/ad preparation, resume client and last-track persistence are disabled; no competitive ticket or finish is generated. This isolates local race preparation and excludes online race admission/limits/ticket latency. Normal startup/menu network reads remain unchanged. No race is driven and no gameplay frame-rate claim is made.

Track compilation is recorded separately from `_start_race`, because selection preparation normally precedes the race tap. The temporary checkpoint/road disk directory starts empty for the first race run and is retained for the second. The owner’s ordinary caches are not cleared. Fixed world order and two repetitions show process-local reuse and cross-process persistence, but are not randomized cold-driver comparisons. Instrumented phases include their asynchronous scheduling/render waits; network `http` observations include main-thread callback delay and cannot be read as pure server or wire latency. Frame gaps are main-loop observations, not GPU timer queries.

Raw account files, exact file manifests, original APKs and diagnostic private draft/preference copies stay under ignored `build/` storage. Public network observations contain allowlisted endpoint categories, durations and no URL, token, headers, response body, account or track identity. The original APK is restored using replace-install; only the task-owned marker/folder is removed after archiving privately. Auth/session and ordinary cache refreshes may legitimately change files, so no blanket post-launch byte-identical-save claim is made. Authored track hashes and PB dictionaries are checked explicitly. No uninstall or clear-data operation is used. Android secure lock requires the owner's physical unlock; its policy is not changed.

The original startup warning about `MenuSnapshotWriter` attachment is retained and inspected as a baseline finding. It is not filtered into a clean-runtime claim. Desktop/native fixtures validate the observer and safety guards; their durations are not tablet results. Failed fixtures, changed-source controls, superseded app versions, secure-lock pauses and initial isolation/export failures remain recorded.
