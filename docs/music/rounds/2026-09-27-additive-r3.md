# R3 — one score, cumulative instruments

Requirements: MUS03/MUS06/MUS09/MUS10/V03/V05/Q01. Standalone audition only.

Owner feedback: “There are somehow too disconnected from each other.” Add an alternative with a simple opening tune, a different instrument joining at each state, and multiple randomly selected options per state that play together.

## Delivered experiment

R2 complete mixes remain available. R3 is an original written score rendered as isolated sampled instruments: acoustic motif → finger bass → piano → acoustic drums → muted guitar → organ answer. Three scored alternatives per instrument produce 729 combinations. Each new drive selects one alternative per instrument; changing intensity, collision and restart retain those choices. An immediately identical random draw is changed in one slot. Manual A/B/C selection is available per instrument, as well as All A/B/C buttons.

All 18 files share 120 BPM, 4/4, eight bars and exactly 768000 stereo frames at 48 kHz (16 seconds). Harmony is D minor / B flat / F / C, two bars each. All pitched note events are chord tones; no held note crosses a chord boundary. The opening motif and final organ response occupy separate note windows. Piano, bass, percussion and muted guitar have distinct accompaniment roles. Alternatives change rhythm, contour and articulation within this contract, rather than changing songs. The earlier conceptual artist references remain emotional context; no artist recordings, melodies or stems were used.

This changes the composition/rendering approach because independent Magenta renders could not establish shared musical identity or exact additive synchronization. TinySoundFont renders GeneralUser GS sampled instruments from explicit note events. It renders three passes and extracts the last loop, retaining prior-phrase release tails. A single common gain preserves the balance across all stems; stems are not independently loudness-normalized. Raw floating-point renders and score files remain beside the exports under `build/music/additive/shared-road-r3-20260927-193446-f6cb87/`.

The license is retained; shipping provenance review remains pending. This bank is audition material, not approved release content.

No subjective listening claimed. Owner review remains necessary for motif, sampled timbres, groove, repetition, balances, all-stage musical development and transitions. Stage changes use the workbench's existing gain ramps, not bar-quantized entrances; changing variants restarts aligned sources at the current playback position with the existing short ramp. Harmonic/scheduling tests cannot establish aesthetic quality. User edits to loop trims can invalidate alignment. Collision behavior remains reset-to-Focus with the existing recovery hold.

No Godot music controller, canonical simulation or shipping assets changed. No phone/device test or Android export was performed. The offline renderer requires Windows Python with numpy and a C++ compiler; dependencies are cached under `.tools`, not bundled into the game. Audio is a local build artifact, reproducible with the generator; scores, hashes, licenses, generator source and evidence establish its provenance.
