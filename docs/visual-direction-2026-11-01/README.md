# Visual direction: review pack

**Revised direction:** The owner clarified that the priority is to make the existing track-card, actual user-created tracks and HUD feel coherent, within realistic creation and rendering constraints. The AI-generated scenes below go beyond that brief and should not be treated as implementation targets. Start with [the grounded direction](GROUNDED_DIRECTION.md) and its mockups. This pack makes no changes to the game.

The following earlier explorations are retained for context only; the revised direction takes precedence:

1. [Simplified race concept](race-simplified-concept.png) — an overhead view exploring a coherent car, road, vegetation and trackside object treatment at a more restrained level of detail. It omits the HUD to focus on the world. The faceted trees and rocks are one exploration, not a requirement to remodel all assets.
2. [Visual coherence concept](visual-coherence-concept.png) — an imagined track preview, racing view and garage presented as one visual family. Use it to discuss continuity of color, materials and vehicle identity. Its environment is much more elaborate than the current game and has no demonstrated mobile performance budget.
3. [Detailed race concept](race-concept.png) — an aspirational illustration of composition, landmark and palette. Its vegetation, water and lighting are not a production target, and its illustrative HUD is incomplete: it omits the pedals and other real controls. Do not use it as a control layout.
4. [Visual tokens](visual-tokens.svg) — an editable vector sheet with the proposed palette, hierarchy and examples of related menu/HUD surfaces. These are proposed design tokens, not values taken from the game. Open the SVG in a browser or vector editor.

All three raster images are AI-generated, show invented locations, and are not gameplay screenshots, track previews, performance evidence, final production assets or approved vehicle models. They must not be used as a literal preview of an existing course. Production previews should depict the actual course and environment. Compare visual direction and composition, not exact geometry or texture density; the written style guide takes precedence.

The concepts were made with the built-in image generation tool using the prompts and existing reference images in [IMAGE_PROMPTS.md](IMAGE_PROMPTS.md). No new game assets or runtime files are involved. Contrast and device validation guidance is in the style guide; neither the generated images nor the token sheet establish accessibility or frame rate.
