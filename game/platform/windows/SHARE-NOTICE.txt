Windows track-link sharing adapter, 2026-10-22

Original project sources: native/windows_share/share_extension.cpp and
native/windows_share/share_runtime.cpp. Build: scripts/dev.ps1 BuildWindowsShare.

The adapter reuses the existing MIT-licensed Godot C++ bindings, revision
e83fd0904c13356ed1d4c3d09f8bb9132bdc6b77, and existing MinGW runtimes.
Retain the notices already supplied in this directory:
GODOT-CPP-LICENSE.txt, GCC-COPYING3.txt, GCC-RUNTIME-EXCEPTION.txt,
MINGW-CRT-LICENSE.txt and WINPTHREADS-LICENSE.txt.

The share runtime uses the existing installed Microsoft Windows SDK and
Visual C++ toolchain, with a static C++ runtime. Its imports are Windows
system libraries. No Windows App SDK, social SDK, new package download,
external runtime service or account connection is introduced.

Both DLLs and share.gdextension belong together. The descriptor records the
runtime dependency for future Windows exports. Existing Android exports
exclude this Windows directory and retain the Android native chooser.
